== Overview

This document specifies how *plan-marshall-mcp* (`PM-MCP`) meets the coding agents installed on a machine: the detection of a coding agent's environment for the operator checks, the Harness Integration Table, the version probes, and the embedded harness bundle with its `bundle-manifest.json` schema. The harness profile schema and the placeholder rendering are specified in the link:https://github.com/plan-marshall/pm-mcp-core/blob/main/doc/specification/harness-profiles.adoc[Harness Profiles Specification].

== Modules

* link:../../../plan-marshall-documentation/doc/specification/module-structure.adoc#module-pm-operator[`pm-operator`]: parts 01 and 02: the operator checks against the harness-detection table, and the `harness` verbs with the drift checks of `pm-operator harness status`
