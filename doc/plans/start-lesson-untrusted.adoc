== What

A lesson is the project's own memory, read as trusted. A lesson whose writing read a review comment, a bot finding, or an issue can carry an injection the screener missed into the next plan; the engine therefore marks such a lesson and screens it when a start takes it as a source. The operator has to see that mark and the screening like those of an issue.

* *Design first*: the package changes link:../design/shared/starting-work.adoc#lesson[Starting Work, A Lesson] and the lesson part of link:../design/terminal-client/18-starting.adoc#lesson[Terminal Client, A Lesson] and has the operator accept it before building it: in the choice (`source-lesson.choose`) a marked lesson shows `untrusted` beside its title; once stored it is screened (`source-lesson.screen`), and the flagged and unscreened waits (`source-lesson.flagged`, `source-lesson.unscreened`) are those of an issue, with the same texts and the same _Use it anyway_ (with a reason) and _Remove it_.
* The start contract carries the mark on each lesson of the choice and the three states for `source-lesson`; the mock runtime offers a marked lesson whose screening is clean, flagged, and failed.
* The source's line shows `untrusted` and `screening` as for an issue, under the rule _Trust_ of the shared design.
* Texts from the message catalogue only.
