== Tasks

. The ABI floor: truncation granted with the write set from ABI 3, `partial(abi=2)` below.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#abi-floor[Job Runtime § ABI Floor].
  Proof: `PmExecIT` truncation tests per applied ABI with their positive controls (PM-WATCH-JOB-41).
. The Landlock scopes from ABI 6.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#landlock-scopes[§ Scopes].
  Proof: `PmExecIT` signal tests with their positive controls, turning over with the ABI (PM-WATCH-JOB-42).
. The system call filter, and its field in the launch report.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#seccomp-filter[§ System call filter]; link:../../../pm-mcp-core/doc/specification/job-runtime/01-pipeline-and-subprocesses.adoc#launch-report[§ Launch report].
  Proof: `PmExecIT` system call tests with their positive controls (PM-WATCH-JOB-43).
. The parent watch of a worker and a probe, on both platforms.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/01-pipeline-and-subprocesses.adoc#runtime-loss[§ Runtime Loss].
  Proof: a worker fixture started from a thread that ends keeps running; one whose parent is killed ends its tree within two seconds, on Linux and macOS (PM-WATCH-JOB-44).
. The macOS sandbox profile: a worker's name lookup and signals to other processes denied.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#macos-confinement[§ macOS Confinement]; link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#worker-name-resolution[§ Name Resolution].
  Proof: on macOS the profile refuses a worker's name lookup and a signal to the runtime fixture (PM-WATCH-JOB-40, PM-WATCH-JOB-42).
. The check mode `pm-exec --self-check`.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#confinement-self-check[§ Confinement Self-Check].
  Proof: on a confining kernel the check mode reports every check with its control, and reports the failed refusal of a fixture that lets it through (PM-WATCH-JOB-45).
