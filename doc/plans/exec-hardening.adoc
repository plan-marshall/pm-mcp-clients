== What

* *ABI floor*: the launcher handles `LANDLOCK_ACCESS_FS_TRUNCATE` from ABI 3 and grants it with the write set; on a
  kernel that offers ABI 2 only it applies the ruleset and reports `confinement: partial(abi=2)`, never `confined`.
* *Scopes*: from ABI 6 the launcher applies `LANDLOCK_SCOPE_SIGNAL` to every job and
  `LANDLOCK_SCOPE_ABSTRACT_UNIX_SOCKET` to a worker and a probe, in a domain the command's descendants share, so the
  launcher's sweep still reaches them.
* *System call filter*: the seccomp filter of the specification, compiled into the launcher and installed as the last
  step before `execve` of the command (after the Landlock ruleset and a worker's namespaces): the architecture check,
  the refused namespace, mount, kernel-interface and socket-family calls, `clone3` and `io_uring` with `ENOSYS`; the
  launch report carries `seccomp`; a kernel that refuses the filter makes the launcher exit `126`.
* *Parent watch*: for a worker and a probe the launcher stays the job's process on both platforms, notes the
  runtime's PID, and ends the command's tree when its parent is no longer that process (on macOS through the process
  tree it records itself); no `PR_SET_PDEATHSIG`.
* *macOS sandbox profile*: for a worker the lookup of `com.apple.mDNSResponder` and `com.apple.dnssd.service` is
  denied; for every job `signal` and `process-info*` with target `others` are denied.
* *Check mode*: `pm-exec --self-check` under a worker's confinement and egress proxy, with the fixture sets the
  runtime passes; it runs each check with its positive control and writes one JSON line with every result, like the
  launch report.

== Done When

`PmExecIT` under Landlock, per applied ABI: the truncation, signal, and system call tests of PM-WATCH-JOB-41,
PM-WATCH-JOB-42, and PM-WATCH-JOB-43 pass with their positive controls, each assertion turning over with the ABI where
the watch item says so; a worker fixture started from a thread that ends keeps running and one whose parent is killed
ends its tree within two seconds (PM-WATCH-JOB-44); the check mode reports every check and its control on a confining
kernel and reports the failed refusal of a fixture that lets it through. On macOS the profile refuses a worker's name
lookup and a signal to the runtime fixture, and the parent watch ends a worker's tree.
