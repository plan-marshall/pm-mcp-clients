== Tasks

. The encoder of `pm-api` removes, from every string value of a response and of an event's `data` on `/api/v1`, the code points of the classes the Unicode stage of the ingestion validator removes, in one pass; line feed and tab stay.
  Anchor: link:../../../plan-marshall-documentation/doc/specification/runtime-model/01-processes-and-transport.adoc#client-text-hidden-characters[Runtime Model § No Hidden Character Reaches a Client].
  Proof: a contract test over every resource type and every event of the catalogue that carries a string: a value holding a right-to-left override, a zero-width space, a tag character, `ESC`, and a lone surrogate arrives without them, and line feed and tab survive (PM-WATCH-RUN-18).
. The mock runtime serves its scenarios through the same encoder, so that a scenario text holding a hidden character reaches both clients without it.
  Anchor: link:../../../plan-marshall-documentation/doc/specification/runtime-model/01-processes-and-transport.adoc#client-text-hidden-characters[Runtime Model § No Hidden Character Reaches a Client].
  Proof: a mock scenario with a chat reply whose code block holds a right-to-left override and a zero-width space; the web app's end-to-end test copies the block and reads back the text without them, and the terminal client's test prints it without them.
