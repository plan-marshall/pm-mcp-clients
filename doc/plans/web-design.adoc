== What

A thorough visual design of the web app, made with Claude Design and reviewed by the operator before any implementation:

* *Design system*: colour tokens for light and dark, typography, spacing, the components every view uses (step bar, consent, check list with checkmark and error, preselected choice, overview with drill-in, table and its list form, progress and model at work, error and fix), the harness monograms, and the icon set.
* *Views*: every state of the onboarding (web side of link:../../../plan-marshall-documentation/doc/design/02-onboarding.adoc[the onboarding design]), the pairing and start pages of UC-WEB-1, and first views of the plan drill-down (UC-WEB-2) and the plan designer (UC-WEB-3) at the level the use cases allow; each at desktop and phone width.
* *Behaviour*: what changes when a check reports, while a model works, on a lost connection, and on a revoked device; keyboard use and accessibility (contrast, focus, screen-reader labels).
* *Technology spike*: the framework and build under the response headers of the web listener (`script-src 'self'`, Trusted Types, no inline script or style), one live-updating view and one drill-down; the result decides the toolchain of `web-app-foundation` and names the dependencies to ask the operator for (link:../../../plan-marshall-documentation/doc/discussions/open-questions.adoc#web-app-toolchain[Open Questions, Front-End Toolchain]).
* The accepted design: the Claude Design artifact linked from `doc/design/`, with the decisions and the design tokens written there.
