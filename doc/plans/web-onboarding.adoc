== What

* The onboarding route and the start and pairing pages as designed in `web-design`, rendering the states the runtime reports; one route, done steps read-only.
* Every view at desktop and phone width, light and dark, with the behaviour of the design (check lists, consent, model at work, lost connection).
* The scenarios shared with `cli-onboarding`; a scenario missing for a web case is added there.
* The machine settings (UC-ONB-10): the aspects again, the remembered consents with their withdrawal, the documents mode, a token rotated or replaced; the page of a device whose network listener was turned off.
* The paired devices in the machine's settings (UC-ENT-2).

== Done When

Every scenario of the onboarding and of the start of the web app (UC-ENT-1) passes as a view test; the same scenarios pass in the terminal (`cli-onboarding`); no text is written in the app's code.
