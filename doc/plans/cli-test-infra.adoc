== What

* Dialogue tests of `pm-operator` against the mock runtime: a test starts the mock runtime with a scenario, drives an interactive verb with scripted key presses, and compares the terminal output with a recorded transcript; the interactive terminal the operator checks require is provided for the test (a pseudo terminal, or a test seam the operator checks accept only in tests, decided here; a library for it is asked for first).
* Transcript files beside the scenarios; a changed transcript shows as a diff to review, never as a silent update.
* The native-image spike of the console's line editor (JLine 4, link:../design/terminal-client/README.adoc#open-points[Terminal Client, Open Points]): size and time to the first prompt with and without it, terminal resize and `Ctrl+C` in the native binary, the native libraries of `jline-native` kept out; the console's transcript tests drive it through a pseudo terminal.
* The same tests in the JVM and against the native binary in the integration-test profile.

== Done When

A dialogue of the existing verbs (`status`, `web pair`) runs as a transcript test against a scenario, in the JVM and native; a deliberately changed text makes the test fail with a readable diff.
