== What

* Relay rule 6: the relay carries its generation as `PM-MCP-Generation` on a session connection and restarts in the same generation.
* Relay rule 7: host markers are passed on as `PM-MCP-Host-Marker`.
* The session-generation store is a Milestone 3 task of `pm-mcp-core`; this task delivers what the relay sends and proves it against the stub daemon.

A session relay has no generation of its own today: the relay sends `PM-MCP-Generation` only for a worker, whose generation comes from its environment. The generation of a session is issued by the daemon from the session-generation store. Relay rule 7 (host markers) can be delivered now; relay rule 6 is delivered when that store has a work package and is done. Split the package there if rule 7 is wanted first.
