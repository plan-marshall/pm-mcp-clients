== What

* The user symlinks of `pm-mcp` and `pm-operator`, the versioned installation directory, and the switch of the symlinks at an upgrade, as far as the specification gives them to the client binaries; the drain of the old runtime is link:../../../pm-mcp-core/doc/plans/runtime-lifecycle.adoc[`pm-mcp-core` / `runtime-lifecycle`].
