== Tasks

. The listed read mode of `pm-exec`, used by a worker launch; `--deny-read` with it is a usage error.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#worker-read-set[Job Runtime § Worker Read Set].
  Proof: `PmExecIT` under Landlock: a job in the listed mode reads its `--read` paths and its write set and fails to read a file directly in the home directory, `<PM_MCP_BASE>`, and a sibling of a listed path; the same job without the mode reads the home directory (matched control); `--deny-read` with the mode exits `64` (PM-WATCH-JOB-38).
. The macOS sandbox profile grants a worker the same listed read set.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#worker-read-set[Job Runtime § Worker Read Set].
  Proof: the cases of task 1 in `PmExecIT` on macOS.
. `headless.readable_paths` in every shipped profile document of `pm-api`.
  Anchor: link:../../../pm-mcp-core/doc/specification/client-profiles/01-profile-schema.adoc#headless-readable-paths[Client Profiles § Readable Paths].
  Proof: every shipped profile document validates with the member.
