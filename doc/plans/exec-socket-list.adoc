== Tasks

. The socket list: an option naming a socket the job may connect to; from Landlock ABI 9 `LANDLOCK_ACCESS_FS_RESOLVE_UNIX` is granted only by it, no longer with the read and write sets, and the runtime socket of a worker is passed on it instead of as a read rule.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#pathname-sockets[Job Runtime § Linux Filesystem Confinement, Unix sockets].
  Proof: `PmExecIT` per applied ABI: a confined worker and a confined `build` job fail to connect to a fixture server's socket in `/tmp` that another domain created, from ABI 9 on, and connect below it (asserted as such); a socket on the list connects; a socket the job binds itself in `/tmp` connects on every ABI; a worker's relay reaches the runtime socket through the list (PM-WATCH-JOB-36).
. The macOS sandbox profile admits a job's Unix socket connections only to its socket list and to sockets the job created.
  Anchor: link:../../../pm-mcp-core/doc/specification/job-runtime/02-confinement-and-environment.adoc#macos-confinement[Job Runtime § macOS Confinement].
  Proof: the cases of task 1 in `PmExecIT` on macOS, for a worker and a `build` job.
