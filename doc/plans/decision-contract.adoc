== What

* *Specification first*: the package writes its part of the specification into `plan-marshall-documentation` as part of its own work (link:../../../plan-marshall-documentation/doc/discussions/client-specification-changes.adoc#slicing[Specification Changes for the Clients, Packages]), from the use case once it is agreed, and opens that pull request beside its own; the proposal's rows it writes are removed from the proposal.
* *Contract*: The Decision Structure, Answers in the Operator's Own Words, Answers from the Terminal Client: the decision with its parts, options, support, recommendation, revision, and evidence; the answer, the interpretation, and the read-back; the channel `cli` with its device; the list of open decisions across scopes; their events and error codes; the decision scenarios of the mock runtime (`decision-<case>`).

== Done When

The specification of the use case's changes is merged in `plan-marshall-documentation`; every record and event type has a round-trip test of its codec, and every closed list is an enumeration a test compares with the specification; every scenario loads and is served by the mock runtime, and a test per scenario asserts the representation a client receives.
