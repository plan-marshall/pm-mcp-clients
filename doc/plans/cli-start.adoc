== What

* `plan add`, `epic add`, `recipe run` as direct verbs: the sources as arguments, the dialogue for every state without one, `--no-input` stopping with the state it needs.
* The list of sources with lines updated in place while a source is fetched and screened, offering only the keys of the kinds that combine; copy or move asked only while the machine's mode is `ask`; a flagged issue printed as plain text; an issue or a pull request refused for the forge's rate limit with the time it resets; an unscreened source with _accept it as untrusted_; a pull request's changed files marked untrusted; a recipe's ready step; the landing of a plan from local changes asked where the project's is `landing.files`; an open entry offered to continue; the decomposition of a new epic as the third step, with its checks, its instruction and read-back (`decomposition.instruct`, `decomposition.read-back`), and chat (`h`), the epic's scope never asked, the chat built here as the dialogue every chat uses (its transcript, each proposed change read back with accept and reject, ended by an empty line); the explorer's actions `p`, `e`, and _Continue starting_; the start chat (`h`) at the list of sources once a source is stored and every source from outside the machine is screened, its accepted description stored.
