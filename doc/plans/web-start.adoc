== What

* Starting a plan or an epic and running a recipe as screens: the list of sources with their progress, the editor of a description, the picker of files over the server's listing, copy or move, copy or move only while the machine's mode is `ask` (copy preselected), the issue field with the forge recognised and the grant (its _No_ failing the source), an issue or a pull request refused for the forge's rate limit with the time it resets, a flagged and an unscreened source, a pull request with its changed files marked untrusted, a lesson, the local changes, the kinds offered by the rule of `start.sources`, the ready step (also a recipe's), the local changes not offered while the project's landing is `landing.files`, with the reason naming the project's setting, adopting an existing epic among the sources of an epic's start (`start-epic.sources`, `start-epic.adopt`, its failure `start-epic.adopt-failed`), the decomposition of a new epic with its instruction, read-back, and chat, the chat panel built here as the one every chat uses (its transcript, each proposed change read back with accept and reject, the message field, ending it); the start chat beside the list of sources once a source is stored and every source from outside the machine is screened, its accepted description stored; leaving and continuing; at desktop and phone width, light and dark.
