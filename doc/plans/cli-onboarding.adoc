== What

* `pm-operator start [--auto] [--pair]`, `pm-operator onboard [--auto]`, and `pm-operator config <aspect>` as designed in `cli-design`, rendering the states the runtime reports; no step order or rule in the client.
* The scenarios of every case the use cases name (each consent answered no, each check failing, stop and resume, the automatic run), in `pm-mock-runtime`.
* Texts from the catalogue only, in English and German.

== Done When

Every scenario of the onboarding and of `start` passes as a transcript test, in the JVM and native; no text is written in the client's code (a test fails for a literal user-facing string).
