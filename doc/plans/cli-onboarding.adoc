== What

* The console `pm-operator` (the entry, the console commands, pushed questions and their answers) and `pm-operator config <aspect>` as designed in `cli-design`, rendering the states the runtime reports; no step order or rule in the client. The line editor is JLine 4 (`jline-reader`, `jline-terminal`, `jline-terminal-ffm`), approved by the operator; its version is managed in `pm-mcp-parent`.
* The scenarios of every case the use cases name (each consent answered no, each check failing, stop and resume, the automatic run), in `pm-mock-runtime`.
* Texts from the catalogue only, in English and German.

== Trace

Requirements, specification sections, use cases, and the design documents both clients share stay in `plan-marshall-documentation` and are only referenced here; the designs of the clients are in this repository (`doc/design/`). == Done When

Every scenario of the onboarding, the entry, and the console passes as a transcript test, in the JVM and native; no text is written in the client's code (a test fails for a literal user-facing string).
