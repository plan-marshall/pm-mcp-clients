== What

* The module `pm-web-app` with the toolchain the spike of `web-design` chose and the operator approved: pinned Node and npm, the build as a static app inside the response headers of the web listener, packaged as a resource JAR.
* The design system of `web-design` as code: tokens, components, light and dark.
* Test infrastructure: unit and component tests; tests of whole views against the scenario files of `pm-mock-runtime`, answering `fetch` and the event streams from them; a browser test of one flow against the started mock runtime if the operator approved a browser test runner.
* Development against the mock runtime: the dev server forwards `/api` to its loopback port.
* The catalogue loaded per area from the runtime; no text in the app's code.

== Done When

The module builds in the reactor and its tests run in `verify`; a view renders a scenario state in a test; the built app runs under the listener's headers without a policy violation (a test fails on one).
