== What

* *Order*: the terminal client drops its own sort of projects and plans by last activity (`OverviewFormatting`) and keeps the order served; the web app already shows it as served. The mock runtime serves the stable order, and a test shows that an activity event moves no row.
* *Size*: `plan.change.size` in the head of the plan view and in the completion report (link:../design/shared/plan-view.adoc#change-size[Plan View, Change So Far]); the contract carries the size and the count of unplanned changes, both absent before the first capture.
