== What

* *Design first, for the work list*: in a window of the split breakpoint or wider (link:../design/web-app/view-density-and-filtering.adoc#breakpoint[The split breakpoint]), the plan view and the epic view hold a collapsible list of the running work beside them: the same rows and markers as the overview, in the order served, the open item marked with `aria-current`. Moving to a neighbour takes one click and keeps the list's place; this browser remembers whether it is open. Below the breakpoint and in the terminal client nothing changes. The package writes it into link:../design/web-app/README.adoc#shell[The App Shell] and has the operator accept it before building it.
* *Add a plan on the row* (link:../design/shared/project-explorer.adoc#project-row[Project Explorer, A Project]).
* *Notifications*: only what is new, and together (link:../design/shared/decisions.adoc#announce[Decisions, Announcing a Decision]); a test covers a reconnect that raises none and a burst that raises one.
