== What

* The module `pm-mock-runtime`: the local API `/api/v1` on the Unix socket of a given `PM_MCP_BASE` with the runtime token and runtime record a client looks for, and on request on a loopback web port; the control paths `/mock/`; one minimal HTTP/1.1 and Server-Sent Events server over a JDK `ServerSocketChannel` for both.
* The scenario format: states with their representation and links, timed events, automatic transitions; every scenario decoded with the codecs of `pm-api` at load, a request that matches no link answered `mock_no_route`.
* The stub daemon of the integration tests of `pm-relay` and `pm-operator` replaced by the mock runtime with scenarios of their own; the stub removed.
* The scenarios of this milestone's client-facing endpoints (status, web access and pairing).

== Done When

A test per rule of the scenario format (an invalid representation, an unknown link relation, and a dangling `next` fail the load with file, state and field; an unmatched request answers `mock_no_route`); `pm-operator status` and the relay run against it in their integration tests; the stub daemon is gone; the module is not deployed and depends on `pm-api` only (dependency guard).
