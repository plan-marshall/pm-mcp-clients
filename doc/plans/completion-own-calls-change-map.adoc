== What

* *Design first*: add the rows _Own calls_ and _Change map_ to link:../design/shared/completion-report.adoc#layout[Completion Report, Layout] and have the operator accept them: the own calls apart from _Decisions_, shortcuts first with their limit and the condition that ends them, each with the self-review's judgment (`consistent`, or `conflicts` with the item named); the change map as the fixed-width text diagram the runtime renders, `partial` or `indeterminate` with its cause, and its lists one step away.
* The contract: the completion resource `GET /api/v1/plans/{plan_id}/completion` gains the own calls and the change map as the runtime records them; the mock runtime serves a fixture plan with a design call, a shortcut, a replaced dependency, and a partial map.
* Both clients show the two rows from the contract and compute nothing; the diagram is shown as delivered, in a fixed-width font, never redrawn.
