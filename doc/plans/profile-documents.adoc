== What

* Move the detection signals, their precedence, the process markers, the session id variable, and the identity probes out of the Java constants into the `detection` and `identity` objects of one profile document per harness.
* A generic reader of these two objects with the streaming API; it skips the rest of the document and names no harness.
* Build test: no production class of this repository names a harness; every shipped document has both objects in the closed form of the schema, with pairwise different `precedence`.
* The comparison of the Host Integration Table with the documents needs the documentation checkout; plan where that test runs (this repository with the sibling checkout, or the documentation repository) in the trace matrix.
