== What

* `plans`: the full-screen view of the overview on JLine 4 alone (`Display`, `BindingReader`, `KeyMap`), its two levels and two views of a project, the keys, live updates from the event stream with the selection anchored by id, notices held while it is open and summarised when it is left, `console.full_screen`, and the selection stored in the user's state directory.
* `status` as the tree of running work (`--project`, `--by epic`), the accessible path and the fallback of `plans`.
* A plan whose worker is off track marked apart from what needs the operator.
* Ended work: the ended plans and epics of a project with every outcome and end, each opening its view as it ended.
* The view model kept apart from the drawing; texts from the catalogue only.

== Done When

Every scenario of `overview-contract` passes as a transcript test of `status` and as a screen test of `plans` (a virtual terminal asserting the screen after each key), in the JVM and native; leaving the view restores the terminal also after an error; the stored selection reopens the view where it was left, and falls back as the design says.
