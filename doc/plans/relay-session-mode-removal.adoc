== Tasks

. `pm-mcp serve` has the one form `serve --job`: the option `--client`, the session mode (`RelayMode.session`) and the session headers it sends (`PM-MCP-Client`, `PM-MCP-Host-Marker`) are removed; `serve` without `--job` is a usage error.
  Anchor: link:../../../plan-marshall-documentation/doc/specification/cli-and-security/01-cli-and-installer.adoc#command-tree[CLI, Coordination & Security § Command Tree]; link:../../../plan-marshall-documentation/doc/specification/runtime-model/03-relay.adoc#relay-rules[Runtime Model § Relay Rules].
  Proof: `ServeCommand` refuses `serve` without `--job` and `serve --client <id>` with exit `2`; `RelayTest`, `PmMcpTest` and `PmMcpProcessIT` cover the job relay only.
. The harness detection keeps only what the job relay and the bundles use; a member that served only the session mode is removed.
  Proof: no reference to the session mode remains (`git grep -n "session(" pm-relay/src`).
