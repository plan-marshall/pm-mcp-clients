== What

* Resource records of the resources the daemon serves in this milestone (runtime status, web access, runtime stop, credential status, the runtime-wide event stream), the link relations, and the closed error codes.
* The JSON codec over the streaming API of `jackson-core`; no `jackson-databind`.
* The TOON codec is the undecided point of PM-WATCH-MOD-4 (one encoder in `pm-api`, or a JSON-only API). Decide it first, as a correction task of the documentation pull request, and delete the watch item.
