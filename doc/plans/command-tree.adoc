== What

* Every command of the command tree whose server side this milestone delivers, each a request through the socket client of `pm-api` with the on-demand start: among them `runtime install|uninstall`, `audit verify`, and `drain`. A command whose server side belongs to a later milestone is recorded `out of slice` in the trace matrix with that milestone.
* The runtime-free verbs read only the closed list of files, through the read-only codec in `api.files`; a test fails for any other file read.
