== What

* The explorer of the projects as the web app's first view: groups, a project's row and actions, favourites and their order, sort and filter; the onboarding of a project as its screens, with the build environment the terminal client last captured; at desktop and phone width, light and dark.
* The release and the unenrolment of a project with their confirmation (UC-PRJ-3).
