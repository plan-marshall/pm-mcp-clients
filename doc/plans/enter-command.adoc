== What

* `pm-mcp enter` sends what the host shell sees as one request and writes no store: the declared client, the environment signature from the host-detection data, the host build probe with its timeout, the hint file.
* The bundle drift check of `enter` belongs to Milestone 7.

The request carries all three identity tiers' inputs; a probe that hangs is cut at its timeout and records no build; both nestings of two hosts are detected as specified.
