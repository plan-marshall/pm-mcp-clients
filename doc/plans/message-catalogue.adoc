== What

* The message catalogue: keys `<area>.<view>.<element>.<part>`, one pack per area and locale (`messages/<area>.<locale>.properties`, UTF-8, ICU message format), the lookup by key, locale and arguments.
* English complete as the base, German from the start, addressing the operator with _du_.
* The build checks: a key missing in a pack, a key not in English, a differing argument, and a glossary term translated in a German text each fail the build.
* The route `GET /api/v1/messages/{locale}/{area}` added to the mock runtime of `mock-runtime`, which serves the packs to the web app; the real endpoint follows with the runtime.
