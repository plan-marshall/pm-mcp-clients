components of the design system (link:../visual-design/plan.adoc[VD-S-01 to VD-S-03]). Each step is one pull request

== Order and Parallel Work

* UX-S-01 first; it changes the frame every view sits in.
* UX-S-02, UX-S-03, UX-S-04, UX-S-06 can run in parallel after UX-S-01.
* UX-S-05 needs `ActionBar` styles from VD-S-03.
* UX-S-07 to UX-S-12 follow UX-S-04, in the order of value: plan, decisions, running work, start, the rest.
* UX-S-13 travels with each step; the last pull request closes it.
