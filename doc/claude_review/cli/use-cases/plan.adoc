The steps are in order. Each step is one pull request. Each step names its proposals and the tests that must change.
Build and test through Maven only: `./mvnw -pl pm-operator verify -Pintegration-tests`.

[#CLI-UC-S-01]

Proposals:: link:proposals.adoc#CLI-UC-P-02[CLI-UC-P-02]

. Add a PTY test `PauseDialogueIT` (`transcript/`): `q` leaves and sends nothing; `9` re-asks; Enter takes the
  preselection.
