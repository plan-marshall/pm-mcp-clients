This folder states how well `pm-operator` implements the use cases it serves
(link:../../../../../plan-marshall-documentation/doc/UseCases.adoc[Use Cases]), and which use cases need changes. The
set comes from `doc/design/terminal-client/README.adoc` and the `Design::` line of each use case. It holds all use
cases except two: UC-PLN-3 (the process designer, web only) and UC-PRJ-4 (a draft without design).

Verdicts (the scale of the web review):

`conforms`:: The flow and its variations are there. Only small defects remain.
`partial`:: The main flow works. Some variations or outcomes are absent.
`deviates`:: The client does something other than the use case says.
`missing`:: There is no implementation.
`not verified`:: The mock does not show the state, or the act was not run. The test named is the only evidence.

Severities of findings:

`blocker`:: The act does harm or cannot be done.
`major`:: The operator is misled or slowed down a lot.
`minor`:: A defect the operator can work around.
