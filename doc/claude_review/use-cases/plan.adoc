The steps run after the foundation of link:../cross-cutting/plan.adoc[Cross-Cutting, Plan] and the components of
link:../visual-design/plan.adoc[Visual Design, Plan]. Steps UC-S-01 and UC-S-08 do not depend on them and can start at
once.

Every step is one pull request in the usual flow (branch, commits, pull request), with its unit tests and the e2e specs
named. Each step updates the design document it touches in `doc/design/` in the same pull request.
