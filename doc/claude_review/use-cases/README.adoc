Verdicts:

`conforms`:: The flow and its variations are there. Only small defects remain.
`partial`:: The main flow works. Some variations or outcomes are absent.
`deviates`:: The app does something other than the use case says.
`missing`:: There is no implementation.
`not verified`:: The mock does not show the state in Chrome. The e2e spec named is the only evidence.
