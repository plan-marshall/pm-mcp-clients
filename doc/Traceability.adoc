What each requirement of the link:../../plan-marshall-documentation/doc/Requirements.adoc[Requirements Document] that
the modules of this repository implement is implemented by, verified by and documented in. A work package adds the
lines of the requirements it implements here, in its own pull request: `Implementation:` links the production code,
`Verified by:` the automated tests, and `Documentation:` the specification part of this repository that states it. A
requirement that is not implemented in this repository says so; a line is never invented.

The granularity is the module for `Implementation:` and the module's test tree for `Verified by:`, unless a single
class or test is named: the clients are specified by their module, and the class-level entry is added by the work
package that touches it. The links into this repository are relative; a link into `plan-marshall-documentation` is a
relative sibling path that resolves with the repositories checked out beside each other.

A requirement implemented in another repository is traced there. The lines of the requirements whose specification
section stayed in `plan-marshall-mcp` are recorded in its traceability.
