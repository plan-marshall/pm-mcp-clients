[#texts]
== Texts

Keys of the area `control`, shared by both clients (link:texts-and-languages.adoc#keys[Keys and Packs]). The end of a plan and of an epic is labelled _End_ / _Beende_, so that _Cancel_ / _Abbrechen_ in a dialogue means only closing it; the outcome of that end keeps its name, `cancelled` (link:plan-overview.adoc#texts[Plan Overview, Texts]). An act that opens a dialogue which asks for more ends with `…` (link:texts-and-languages.adoc#acts-and-links[Texts and Languages, Acts and Links]). The settings dialogue closes with `common.action.close`, the epic's end dialogue cancels with `common.action.cancel`.

The texts are in the packs
link:../../../pm-api/src/main/resources/messages/control.en.properties[`control.en.properties`] and
link:../../../pm-api/src/main/resources/messages/control.de.properties[`control.de.properties`]; the packs are the
source of these texts, and this design does not repeat them.
