== Texts

Keys of the area `control`, of link:work-actions.adoc#chat[Chatting with the Planning Role]; the chat's action is `control.plan.chat`, `control.epic.chat`, `control.review.chat`, or `start.decomposition.chat` where it is opened.

|Sende sie
