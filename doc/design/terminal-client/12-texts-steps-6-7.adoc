The keys of the landing name its variants: `onboard.defaults.landing.pull_request`, `.main`, and `.files` are the sub-workflows `landing.pull-request`, `landing.main`, and `landing.files`. At the machine level there is no repository, so _Commit on the base branch_ is never checked against a protected base branch here (`onboard.defaults.validate.main_per_project`); that check belongs where a project is known, its setup and a plan's start. The German name of the landing axis is _Abschluss_, since _Landing_ is not in the glossary; _Outline_, _Merge_, _Pull Request_, _Branch_, _Commit_, _Push_ stay as the glossary says.
