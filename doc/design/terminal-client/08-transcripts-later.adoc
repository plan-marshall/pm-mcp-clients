[#t-later]
== Later Changes and Scripts

The first two run a verb as one shell command, as a script does; the others run it in the console.

[#t-config-direct]
=== Arguments as Answers (`config plan-defaults`)

[source,text]
----
$ pm-operator config plan-defaults --landing pull-request --yes
Plans · How should plans run on this machine?
  ✓ Landing   Branch and Pull Request   (--landing pull-request)
  ✓ Method    Test first                (kept)
  ✓ Asking    At the key points         (kept)
    ✓  Branch and Pull Request: GitHub is available
✓ Plan defaults recorded
----

[#t-config-no-input]
=== Stopped at a Choice (`--no-input`)

[source,text]
----
$ pm-operator config harness --client opencode --no-input
Harness · Look for harnesses on this machine?
Needs a choice: --consent scan_harnesses
$ echo $?
3
$ pm-operator config harness --client opencode --consent scan_harnesses --consent probe_harness_login --no-input
  ✓  Looking for harnesses: 2 found
  ✓  Harness   OpenCode 1.9.0   (--client opencode)
    ✓  version 1.9.0 is supported (1.5 – 1.x)
    ✓  logged in
Harness · Enrol OpenCode
Needs a choice: --yes
$
----

[#t-config-project-roles]
=== A Project's Own Roles (`config roles --project`)

[source,text]
----
pm › config roles --project pm-mcp-clients
Roles · project pm-mcp-clients · Give every role a harness and a model
  The machine's assignment applies to all 31 roles here.

    1) Claude Code · opus-5.5      7 roles   from machine
    2) Claude Code · sonnet-5.5   16 roles   from machine
    3) OpenCode · qwen-coder       8 roles   from machine

Keep the machine's assignment? [Enter]   e) adjust roles   ?   › e
    …
    14) qgate       read_only   OpenCode     qwen-coder  —        from machine
    …
Select roles to assign: numbers or ranges, a) all shown   ?n advisory   b) back   › 14
  Harness   1) Claude Code ← from machine: OpenCode   2) OpenCode   › 1
  Model     1) opus-5.5   2) sonnet-5.5               › 2
  Effort    1) low   2) medium   3) high              › 2
    14) qgate       read_only   Claude Code  sonnet-5.5  medium   ✎ project

Save 1 role for pm-mcp-clients? [Enter]   e) adjust more   d) reset to the machine's   b) back   ?   › ⏎
  ✓  31 roles valid
✓ 1 role set for pm-mcp-clients (overrides machine: OpenCode · qwen-coder); 30 follow the machine
----

* Only the changed role is written to the project's assignment; the others keep following the machine, so a later machine change reaches them. `d` removes the project's value of the selected roles.
