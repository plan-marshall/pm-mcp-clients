[#texts-settings-shared]
=== `onboard.settings`: Shared by Both Clients

The texts of the machine settings' own states (`settings.choose`, `settings.documents-mode`, `settings.credential`, `settings.store-credential`), shown alike by the web app (link:../web-app/machine-settings.adoc[Web App, Machine Settings]) and the terminal (xref:08-transcripts-later.adoc#t-settings[The Machine Settings]). The aspects are named by `onboard.step.*` with the summaries of the onboarding's result; the checks of a token are those of `providers.verify` (xref:12-texts-steps-6-7.adoc#texts-onboard-providers[Texts, Providers]).

[#texts-operator-devices]
=== `operator`: Only the Terminal

The terminal's lines of `web devices`, `config`, `config consents`, `config documents`, `credentials rotate|set`, and `config providers --verify`; the names of the list's fields and acts are the shared `devices.*` (link:../shared/paired-devices.adoc#texts[Paired Devices]), the texts of `settings.withdraw` the shared `common.consent.withdraw.*` (link:../shared/consents.adoc#texts[Consents, Texts]). Transcripts: xref:08-transcripts-later.adoc#t-devices[Paired Devices], xref:08-transcripts-later.adoc#t-settings[The Machine Settings], xref:08-transcripts-later.adoc#t-consents[The Remembered Consents], xref:08-transcripts-later.adoc#t-documents[The Documents Mode], xref:08-transcripts-later.adoc#t-credential[A Token Rotated or Replaced], xref:08-transcripts-later.adoc#t-providers-verify[Providers Checked Again].
