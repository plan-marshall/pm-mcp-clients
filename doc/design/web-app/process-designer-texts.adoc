== Texts

Keys of the area `designer`, which only the web app loads (link:../shared/texts-and-languages.adoc#keys[Texts and Languages, Keys and Packs]). The structure and the composed process use the keys of the plan view (`plan.node.kind.*`, `plan.node.state.planned`, `plan.prune.<reason>`, link:../shared/plan-view.adoc#texts[Plan View, Texts]); a changed meanwhile uses `common.conflict.*`. The findings' messages are the runtime's. The last key is the terminal's one line in its `help` (area `operator`).
