# The target of the set is `reports-and-system` -> `system.running`:
#   system-actions-*  the `a` menu of the system view, opened from the console (`system`, then `a`)
#   stop-screen-*     `runtime stop` as it draws, the keys-less screen the dialogue settles on
#   stop-keep-*       `runtime stop` with `k` (keep it running): nothing is sent

#   system-stop-*     the dialogue the `a` menu opens, from `s` on the runtime's entry
#
# The system view is opened from the console, not by the verb: `system` as a shell command prints
# the view once, and only the console opens it full screen (25-system.adoc#commands). The keys after
# the menu capture close it (`a`), leave the view (`q`) and end the console (`exit`).
#
# The keys-less captures come first so that a run of this set against the code before the change
# records the old screen of every target before the keyed captures stop it: before the change
# `runtime stop` sends at once and exits, so a keyed capture has no prompt to type into.
